# 01 Kitex 概览

## 学习目标

- 理解 Kitex 是 Go 微服务 RPC 框架。
- 了解 Kitex 支持 Thrift、Protobuf、gRPC 等协议。
- 理解 Kitex 在 Client、Server、代码生成和服务治理中的角色。

## Kitex 是什么

Kitex 是用于 Go 微服务通信的 RPC 框架，常见能力包括：

- 基于 IDL 生成 Go 代码。
- 提供 Client 调用代码和 Server 骨架代码。
- 支持 Thrift、Protobuf、gRPC 等协议。
- 提供超时、重试、负载均衡、服务发现、中间件等服务治理能力。
- 在公司内部项目中，通常使用内部 Kitex Tool 和内部服务治理体系。

## Kitex 帮你做了什么

| 层次 | Kitex 负责 | 你负责 |
| --- | --- | --- |
| 接口契约 | 根据 IDL 生成 Go 类型和调用接口 | 设计清晰、兼容的 IDL |
| Client | 封装请求序列化、网络发送、错误返回 | 构造请求、处理响应和错误 |
| Server | 封装监听、请求解码、方法分发 | 实现 Handler 业务逻辑 |
| 治理 | 支持超时、重试、负载均衡、中间件 | 选择适合业务的配置 |

## 初学者不要一开始就深挖所有治理项

建议先按顺序掌握：

1. IDL 怎么定义。
2. 代码怎么生成。
3. Handler 写在哪里。
4. Client 怎么调用。
5. 超时和错误怎么处理。
6. 再理解重试、负载均衡、服务发现、中间件。
