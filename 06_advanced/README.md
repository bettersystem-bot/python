# 06 高级构件

## 这一章学什么

这一章会接触三个在工程代码里很常见的异步构件：

- 异步迭代器
- 异步生成器
- 异步上下文管理器

## 异步迭代器

异步迭代器通常配合 `async for` 使用。
它适合“每次取下一个值之前都可能需要等待”的场景。

## 异步生成器

异步生成器同时具备两点：

- 用 `async def` 定义
- 在函数体里使用 `yield`

它适合做“逐步产出数据流”，而不是一次性返回完整列表。

## 异步上下文管理器

异步上下文管理器配合 `async with` 使用。
你可以把它理解成“异步版本的资源申请和资源释放”。

常见场景：

- 建立和关闭网络连接
- 申请和释放异步资源
- 打开和关闭异步客户端会话

## 运行方式

```bash
python3.10 06_advanced/async_iterators_context.py
```

## 观察重点

- `async for` 每次取值前，程序是否会等待
- 异步生成器是不是在逐步产出数据
- `async with` 进入和退出时分别调用了什么
