# 15 线程锁机制

## 这一章学什么

这一章聚焦 `threading` 里的常见锁工具。

你会学到：

- `Lock`：最基础的互斥锁
- `RLock`：可重入锁
- `Semaphore`：限制并发数量

## Lock

`Lock` 用来保护临界区。

临界区就是“同一时刻只能允许一个线程进入”的代码区域。

## RLock

`RLock` 是可重入锁。

它允许同一个线程重复获得同一把锁，适合函数之间互相调用且都需要加锁的情况。

如果用普通 `Lock`，同一个线程第二次拿锁时会把自己卡死。

## Semaphore

`Semaphore` 不是只允许一个线程进入，而是允许最多 N 个线程进入。

适合：

- 限制数据库连接数
- 限制下载并发数
- 限制外部 API 调用并发
