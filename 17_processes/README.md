# 17 多进程并行

## 这一章学什么

线程适合 I/O 并发，但 CPU 密集型任务通常需要多进程。

这一章会讲：

- 为什么多进程可以更好利用多核
- 进程之间为什么不能随便共享普通变量
- 如何用 `multiprocessing.Queue` 传递结果
- 为什么多进程代码要放在 `if __name__ == "__main__"` 下面

## 进程和线程最大的区别

线程共享同一个进程内存，所以共享变量很方便，也更危险。

进程默认不共享内存，每个进程都有自己的地址空间，所以更隔离，但通信更麻烦。

## 运行方式

```bash
python3.10 17_processes/multiprocessing_basics.py
```
