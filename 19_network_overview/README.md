# 19 网络编程总览

## 这一章学什么

这一章先建立网络编程地图，不急着写复杂服务。

你会学到：

- IP、端口、协议分别是什么
- TCP 和 UDP 的核心区别
- socket 是什么
- 为什么网络传输必须处理字节编码
- DNS 解析大概发生在哪里

## IP 和端口

IP 地址决定“找到哪台机器”。

端口决定“找到这台机器上的哪个程序”。

比如：

- `127.0.0.1`：本机回环地址
- `80`：常见 HTTP 端口
- `443`：常见 HTTPS 端口

## TCP 和 UDP

TCP 像打电话：

- 先建立连接
- 数据有顺序
- 丢了会重传
- 成本相对更高

UDP 像寄明信片：

- 不需要先建立连接
- 不保证一定到
- 不保证顺序
- 成本更低

## socket 是什么

socket 是应用程序和操作系统网络协议栈之间的接口。

应用程序不直接操作网卡，而是通过 socket 调用操作系统能力。
