# 07 异步与阻塞代码的衔接

## 这一章学什么

真实项目里，异步代码经常需要调用一些还没有异步版本的旧逻辑。

比如：

- 老库只提供阻塞接口
- 某些文件处理逻辑是同步的
- 临时迁移阶段还没来得及彻底异步化

在 `Python 3.10` 里，`asyncio.to_thread()` 是一个非常实用的过渡工具。

## 为什么不能直接在协程里调用阻塞函数

因为协程所在的线程通常就是事件循环线程。
如果你在这里直接执行阻塞操作，那么：

- 事件循环会被卡住
- 其他协程也会一起停住
- 整个程序的响应性会明显变差

`asyncio.to_thread()` 会把阻塞工作放到线程里执行，让事件循环本身保持流畅。

## 适用边界

`to_thread()` 更适合这些情况：

- 阻塞 I/O
- 耗时不长的同步辅助逻辑
- 迁移期间的兼容方案

如果是特别重的 CPU 密集型任务，通常还要考虑进程池等方案。

## 运行方式

```bash
python3.10 07_bridge/to_thread_bridge.py
```

- 增加 heartbeat 次数
