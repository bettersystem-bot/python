# 08 小型综合项目

## 这一章学什么

这一章会把前面学到的多个知识点串起来，做成一个小型异步项目示例。

这个例子模拟了一个迷你爬虫流程：

- 并发抓取多个页面
- 用信号量限制并发数
- 谁先完成就先处理谁
- 最后汇总成功和失败结果

这里使用的是“模拟网络延迟”，这样你可以稳定观察行为，而不用依赖外部网站状态。

## 这个例子为什么有价值

因为真实业务里的很多异步流程，结构都很像：

- 先准备输入
- 再批量启动 I/O 任务
- 对并发做保护
- 流式接收结果
- 最后做统一汇总

这个示例就是把这条思路缩小成了一个可直接读懂的小项目。

## 运行方式

```bash
python3.10 08_project/mini_crawler.py
```

## 观察重点

- 任务是不是很快就都启动了
- 为什么同一时刻只有有限数量的任务真正进入抓取区
- 为什么结果顺序和输入顺序不一定一样
- 为什么一个失败结果不会把整个汇总流程打断

## 练习建议

- 增加更多 URL
- 调整并发上限
- 给失败任务增加一次重试
- 按耗时对结果排序
- 把汇总结果写入文件
