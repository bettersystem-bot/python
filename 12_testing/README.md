# 12 异步代码的测试思维

## 这一章为什么要补

会写异步代码之后，还要能验证它。

异步测试最重要的不是“引入哪个测试框架”，而是先学会把异步逻辑拆成容易观察的形状。

这一章故意只用标准库，不依赖第三方测试框架，目的是先把测试思维讲清楚。

## 这一章学什么

你会学到：

- 如何用 `unittest.IsolatedAsyncioTestCase` 测试协程
- 如何测试成功路径
- 如何测试超时路径
- 如何测试异常路径
- 为什么每个测试都应该拥有隔离的事件循环

## 为什么用 `IsolatedAsyncioTestCase`

在 `Python 3.10` 中，标准库已经提供了异步测试能力。

`IsolatedAsyncioTestCase` 会给每个测试方法一个相对独立的异步运行环境，避免不同测试之间互相污染。

## 运行方式

```bash
python3.10 -m unittest 12_testing/test_async_service.py
```
