# 01 协程入门

## 这一章学什么

这一章只做一件事：把“协程”这个最小单位彻底弄明白。

你会学到：

- `async def` 到底定义了什么
- 为什么调用异步函数不会立刻执行函数体
- `await` 到底意味着什么
- `asyncio.run()` 在整个过程中扮演什么角色

## 核心概念

普通函数在调用时会立刻执行。

但是异步函数不一样：

```python
async def greet():
    return "hello"
```

调用 `greet()` 时，Python 不会马上执行函数体，而是先创建一个“协程对象”。
只有事件循环开始调度它，它才会真正运行。

## 推荐心智模型

你可以把协程理解成“一份已经写好的任务说明书，但暂时还没开工”。

- `async def`：定义任务说明书
- 调用函数：创建一份待执行任务
- `await`：告诉事件循环，“我这里先暂停，等别的事情结束了再回来继续”
- 事件循环：决定现在轮到谁执行

## `await` 的本质

`await something` 可以理解为：

- 当前协程主动暂停
- 把控制权交还给事件循环
- 等待 `something` 完成后再恢复执行

这就是异步编程里的“协作式并发”。

## 这一章为什么重要

后面你看到的任务调度、并发请求、队列消费、超时控制，本质上都建立在协程暂停和恢复的机制上。
如果这一层没有理解透，后面的 API 很容易背了用法却不懂本质。

## 运行方式

```bash
python3.10 01_coroutines/basic_coroutines.py
```

## 观察重点

跑程序时，请重点观察：

- 协程对象是在什么时候创建的
- 协程函数体是在什么时候真正开始执行的
- 程序在哪一行发生暂停
- 暂停后又是在什么时候恢复的

## 练习建议

- 把 `sleep` 时间改短或改长
- 再加一个 `await asyncio.sleep(...)`
- 自己新写一个协程，然后在 `main()` 里等待它
- 打印更多日志，观察每次 `await` 前后的顺序
