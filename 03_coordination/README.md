# 03 多任务协作

## 这一章学什么

当你已经会创建多个任务，接下来最重要的问题就是：这些任务怎么协作？

这一章会对比三个非常常用的工具：

- `asyncio.gather`
- `asyncio.wait`
- `asyncio.as_completed`

## `gather`

当你想“一次把所有结果都收回来”，并且希望结果顺序和输入顺序一致时，用 `gather` 很方便。

典型场景：

- 并发发起多个请求
- 最后统一拿到全部结果
- 结果顺序必须稳定

## `wait`

当你更关心“哪些任务完成了，哪些还没完成”，而不是只想拿结果时，`wait` 更合适。

典型场景：

- 只等到第一个完成的任务
- 需要区分 `done` 和 `pending`
- 想自己决定后续如何取消剩余任务

## `as_completed`

当你希望“谁先完成就先处理谁”的时候，`as_completed` 很有用。

典型场景：

- 一边跑任务一边展示进度
- 快的结果先处理，不等慢的
- 做流式结果消费

## 运行方式

```bash
python3.10 03_coordination/gather_wait_as_completed.py
```

## 这一章最重要的理解点

这三个工具没有绝对的谁比谁更高级，只有谁更适合当前问题。

你每次选择前，都先问自己：

- 我是不是一定要拿到全部结果？
- 我是不是需要结果顺序和输入顺序一致？
- 我是不是更关心谁先完成？
- 我是不是需要拿到 `done` / `pending` 的集合？

## 练习建议

- 新增一个更快的任务
- 故意让某个任务抛异常，观察 `gather`
- 把 `FIRST_COMPLETED` 改成 `FIRST_EXCEPTION`
- 只拿到第一个结果后，取消剩余任务
