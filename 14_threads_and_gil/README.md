# 14 线程、GIL 与竞态条件

## 这一章学什么

这一章会解释 Python 线程中最容易混淆的两个概念：

- GIL 是什么
- 竞态条件是什么

## GIL 是什么

GIL 全称是 Global Interpreter Lock，全局解释器锁。

在 CPython 中，同一时刻通常只有一个线程在执行 Python 字节码。

这意味着：

- 多线程不适合让纯 Python CPU 计算变成真正多核并行
- 多线程仍然适合 I/O 密集任务，因为等待 I/O 时线程可以切换
- GIL 不等于你的代码天然线程安全

## 为什么 GIL 不等于线程安全

因为一行看起来简单的代码，底层可能分成多个步骤。

例如：

```python
counter += 1
```

可以拆成：

1. 读取 counter
2. 加 1
3. 写回 counter

如果两个线程交错执行，就可能丢失更新。

## 运行方式

## 观察重点

示例里会先演示没有锁的计数器，再演示加锁后的计数器。

没有锁时，结果可能小于预期；加锁后，结果应该稳定正确。
